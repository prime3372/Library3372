# enumerate_primes

## 問題文

クエリタイプ $T$ と整数 $L, R$ が与えられます。

- $T = 1$ のとき、$R$ 以下のすべての素数を昇順に列挙してください。このとき $L = 0$ です。
- $T = 2$ のとき、半開区間 $[L, R)$ に含まれるすべての素数を昇順に列挙してください。

## 制約

- $T \in \{1, 2\}$
- $T = 1$ のとき $L = 0$ かつ $0 \leq R \leq 2^{31} - 1$
- $T = 2$ のとき $0 \leq L \leq R \leq 2^{63} - 1$
- 入力はすべて整数

## 入力

入力は以下の形式で標準入力から与えられます。

```plaintext
T L R
```

## 出力

列挙した素数を昇順に $p_1, p_2, \dots, p_k$ とします。初期値 $h = 0$ から始め、$i = 1, 2, \dots, k$ の順に `library3372/internal/hash/hash_combine.hpp` の `hash_combine(h, p_i)` を適用して得られる 64 bit 符号なし整数を出力してください。
