# weighted_union_find

## 問題文

$N$ 頂点 $0$ 辺の無向グラフが与えられます。各頂点 $i$ ($0 \leq i < N$) には 64 bit 符号付き整数で表されるポテンシャル $p_i$ があり、重みは $2^{64}$ を法として管理されます。以下の $Q$ 個のクエリを順に処理し、最後にすべての連結成分を列挙してください。

- `0 u v w`: $p_v - p_u \equiv w \pmod{2^{64}}$ という制約を追加する。すでに頂点 $u$ と頂点 $v$ が同じ連結成分に属しており既存の制約と矛盾する場合は、この制約を無視する。矛盾しなかった場合は `1`、矛盾した場合は `0` を記録する。さらに、元々異なる連結成分に属していた場合は合併後の代表元と吸収された古い代表元を記録する。
- `1 u v`: 頂点 $u$ と頂点 $v$ が同じ連結成分に属していれば `1` を、そうでなければ `0` を記録する。
- `2 u v`: 頂点 $u$ と頂点 $v$ が同じ連結成分に属していれば $p_v - p_u \bmod 2^{64}$ を 64 bit 符号なし整数値として記録し、そうでなければ `0` を記録する。
- `3 u`: 頂点 $u$ が属する連結成分の頂点数を記録する。
- `4 u`: 頂点 $u$ が属する連結成分の代表元を記録する。
- `5`: 現在の連結成分の個数を記録する。

初期状態では各頂点 $i$ ($0 \leq i < N$) がそれ自身の連結成分の代表元です。クエリ `0 u v w` によって異なる連結成分が合併されるとき、新たな代表元は元の連結成分のうち頂点数が小さくない方の代表元とし、頂点数が等しい場合は $u$ が属していた連結成分の代表元とします。

## 制約

- $1 \leq N \leq 10^6$
- $1 \leq Q \leq 3 \times 10^6$
- $0 \leq u, v < N$
- $-2^{63} \leq w < 2^{63}$

## 入力

```plaintext
N Q
query_1
query_2
...
query_Q
```

## 出力

`library3372/internal/hash/hash_combine.hpp` の `hash_combine` を用いて、以下の手順で計算した 64 bit 符号なし整数値 `ans_hash` を出力する。

1. `ans_hash = 0` と初期化する。
2. 各クエリの処理結果を順に `ans_hash` へ結合する。
   - `0 u v w`: 矛盾しなかった場合は `1ULL`、矛盾した場合は `0ULL` を結合する。続いて、合併が起きた場合は `new_root`、続いて `old_root` を結合し、合併が起きなかった場合は `0ULL` を結合する。
   - `1 u v`: 同じ連結成分であれば `1ULL`、そうでなければ `0ULL` を結合する。
   - `2 u v`: 同じ連結成分であれば `(unsigned long long)(p_v - p_u)` を結合し、そうでなければ `0ULL` を結合する。
   - `3 u`: 連結成分の頂点数を結合する。
   - `4 u`: 代表元を結合する。
   - `5`: 連結成分の個数を結合する。
3. 全クエリ処理後、各連結成分について頂点番号を昇順に並べた配列 `g` を考え、`gh = (unsigned long long)g.size()` から始めて各頂点 `v` を順に `gh = hash_combine(gh, (unsigned long long)v)` で結合する。すべての連結成分についての `gh` の総和 ($\bmod\ 2^{64}$) を `groups_hash` とする。
4. `ans_hash = hash_combine(ans_hash, groups_hash)` とする。
