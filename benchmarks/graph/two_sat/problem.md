# two_sat

## 問題文

$N$ 個の真偽値変数 $x_0, x_1, \dots, x_{N-1}$ と $M$ 個の節 $(x_{i_k} = f_k) \lor (x_{j_k} = g_k)$ が与えられます。すべての節を同時に満たす変数の割り当てが存在するかを判定し、存在する場合はそのような割り当てを 1 つ求めてください。

## 制約

- $1 \leq N \leq 10^6$
- $0 \leq M \leq 2 \times 10^6$
- $0 \leq i_k, j_k < N$
- $f_k, g_k \in \lbrace 0, 1 \rbrace$

## 入力

```plaintext
N M
i_0 f_0 j_0 g_0
i_1 f_1 j_1 g_1
...
i_{M-1} f_{M-1} j_{M-1} g_{M-1}
```

## 出力

条件を満たす割り当てが一意ではないため、割り当て自体はハッシュに含めず、すべての節を満たす割り当てが存在する場合は `1`、存在しない場合は `0` を `ans_hash` として出力する。
